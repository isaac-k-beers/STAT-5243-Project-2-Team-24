## UI/UX Contribution
Wenyang integrated the main user workflow, built on previous works, of the Shiny application, organizing the app into four connected stages: Data Loading, Data Cleaning, Feature Engineering, and Exploratory Data Analysis (EDA). The interface was built to support a smooth end-to-end experience, allowing users to move from raw input data to processed and explored data within a single application.

The UI emphasizes clarity and usability through a structured tab layout, built-in guidance, preview tables, and dynamic controls that update based on the current dataset. The loading component supports both a built-in Citi Bike sample dataset and user-uploaded files in multiple formats,. The design also accounts for robustness: when uploaded datasets do not match Citi Bike-specific feature requirements, the app provides informative fallback behavior instead of failing.

Overall, this contribution focused on making the application interactive, user-friendly, and resilient.
